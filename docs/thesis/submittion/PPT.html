车道线提取

3

本研究针对车道线检测任务构建了多阶段处理框架，结合传统图像处理，保证车道线检测的准确性与健壮性。

颜色分割

将RGB图像转换为HSV色彩空间，提取车道线区域（主要是黄色和白色）

多尺度DoG边缘检测

应用不同尺度的高斯差分，捕获不同清晰度的车道线

边缘增强

通过形态学处理增强边缘连续性，解决车道线断裂或模糊问题

区域限定

定义多边形ROI区域，仅保留图像下部可能含车道线区域

直线检测

应用概率霍夫变换检测边缘图中的直线段，根据斜率分为左右

车道线拟合

对分类线段点集应用二次多项式拟合，获得平滑连续车道线表示

主要特点

  • HSV色彩空间对光照变化不敏感，能有效减少背景干扰
  • 多尺度DoG策略利用不同尺度信息的互补性，显著提升检测完整性
  • 形态学处理增强边缘连续性，解决车道线断裂问题
  • ROI蒙版减少处理区域，提高计算效率并降低误检率
  • 二次多项式拟合适合道路曲率变化平缓的特点，避免高阶多项式的过拟合风险

模型蒸馏及量化

4

模型蒸馏

模型蒸馏（Model Distillation）是一种旨在实现模型轻量化与高效推理的知识压缩技术。其核心思想是将一个大型且性能优越的"教师模型"所学习到的知识，迁移到一个结构更为精简的"学生模型"中。

软标签学习

学生模型不仅学习传统的硬标签，更重要的是，学习教师模型输出的软标签（softmax概率分布），获得类别间关系的深层信息。

损失函数

使用交叉熵损失和Kullback-Leibler散度度量学生与教师模型输出差异并指导学习过程。

模型量化

模型量化（Model Quantization）是一种常用的模型压缩与加速技术。它通过将模型参数和计算从高精度（FP32、FP16等）转换为低精度（INT8），可以在推理时有效减少计算资源消耗。

静态量化

利用校准数据对模型权重和激活进行量化参数的统计和校准，将其统一映射为低精度格式。

动态量化

在推理过程中，动态地将部分权重或激活从高精度转换为低精度。

蒸馏损失函数

边界框损失

MSE(Sbox, Tbox)

置信度损失

KL(Softmax(Tconf/T) || Softmax(Sconf/T))

分类损失

KL(Softmax(Tcls/T) || Softmax(Scls/T))

KL 散度是用来描述两个分布之间的信息损失
本文使用这种方式用来指导学生模型向KL降低方向调整，从而能得到较低的Loss

最终损失 = Ldet + λKD · (Lbox + Lconf + Lcls)

改进的DeepSORT框架

DeepSORT将目标的外观特征与运动状态信息融合，构建多元相似度度量机制。在计算关联代价时，同时考虑外观相似性和运动连续性。

核心组件

检测关联模块

将当前检测结果与已有轨迹关联，使用加权马氏距离和外观特征距离

卡尔曼滤波模块

通过预测和更新两阶段，估计目标运动状态

轨迹管理模块

维护暂存、确认和删除三种轨迹状态

匹配算法模块

使用匈牙利算法求解全局最优分配方案

轻量级特征度量

考虑到嵌入式设备资源限制，对传统DeepSORT特征度量方法进行了简化和优化，主要使用IoU作为目标关联度量标准。

IoU计算

IoU(A,B) = Area(A∩B) / Area(A∪B)

关联度量函数

dIoU(i,j) = 1 - IoU(i,j)

当dIoU(i,j) ≤ tIoU时认为有关联可能性

运动轨迹预测算法

基于目标当前和历史状态，推断其未来可能的位置。线性预测模型简洁而高效，部署性能良好。

线性预测模型

[xt+1, yt+1] = [xt, yt] + [vx, vy]·Δt

碰撞时间计算模型

碰撞时间(TTC)是评估风险紧迫性的核心指标，表示在当前运动状态下，两个物体发生碰撞所需的时间。

TTC = d/|vrel|

d是两物体间的距离，vrel是相对速度

TTC阈值通常设置在1.5秒到5秒之间。低于1.5秒被认为是危险状态，需要立即采取措施；而高于5秒则被视为安全状态。

综合风险评估模型

碰撞风险评估不仅考虑时间距离，还综合分析空间关系、相对运动状态和环境条件等多种因素。

时空风险因子

基于TTC值划分风险等级，采用分段函数形式

道路边界风险

评估物体是否可能偏离道路，使用三级区域划分

相对运动状态风险

考虑物体间的相对速度、加速度和接近角度

风险评估分段函数

风险分值计算

Risk1 = { 1, 若TTC < Tcritical
e-λ(TTC - Tcritical), 若Tcritical ≤ TTC < Twarning
0, 若TTC ≥ Twarning }

最终风险评分

Risktotal = ∑kwk · Riskk

分级预警机制

强预警 (Risk > 0.8)

紧急危险情况，需要立即采取措施避免碰撞

弱预警 (0.4 ≤ Risk ≤ 0.8)

潜在风险情况，应保持警惕并准备采取措施

正常 (Risk < 0.4)

安全状态，正常驾驶无需特别关注
