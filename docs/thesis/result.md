# 基于深度学习的车道障碍检与碰撞预测方法研究



## 摘要

摘要  
针对传统车辆防撞系统硬件成本高、环境适应性差的问题，本文提出一种基于嵌入式视觉的实时防撞预警系统。通过构建改进的YOLOv5su-ESP32轻量化检测网络，结合双流特征融合架构实现复杂道路场景的精准感知。在算法层面，设计动态通道剪枝策略使模型参数量降低42.7%(7.2M→4.1M)，采用混合精度量化技术将推理速度提升至28FPS；在系统层面，开发基于DeepSORT的多目标跟踪模块，并建立融合相对速度、距离衰减因子和道路曲率的动态风险评估模型。实验表明：在BDD100K数据集上，本系统在640x640分辨率下达到63.3%的mAP@0.5，相比基线YOLOv5s提升0.8%；实车测试中，系统端到端延迟控制在86ms以内，雨雾天气下的误报率较传统方案降低37.2%。研究成果为低成本智能驾驶辅助系统提供了可行的技术实现路径。

关键词：嵌入式视觉；轻量化目标检测；碰撞风险评估；YOLOv5优化；智能交通系统
