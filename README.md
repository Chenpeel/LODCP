## 目录功能说明

### 🚘 firmware
存放嵌入式设备固件代码，包含C++实现的各功能模块，用于在实际设备上运行的车道障碍检测和碰撞预测系统。主要包含目标检测、目标跟踪(DeepSORT)、车道区域检测和碰撞时间预测(TTC)等核心功能模块。

### 🐍 main_py
Python语言实现的主程序，主要用于开发和测试算法。包含Fast-SCNN语义分割模型实现、车道区域检测算法和碰撞时间预测(TTC)算法等，是算法原型的Python实现版本。

### 🧠 models
预训练模型存储目录，包含不同版本的目标检测和语义分割模型：
- **fastscnn**: 用于车道线和道路区域分割的Fast-SCNN模型
- **v5nu**: 轻量级YOLOv5n模型，体积小、速度快但精度略低
- **v5su**: 标准YOLOv5s模型，精度更高但速度较慢
- **v5su_t_nu**: 混合优化模型，平衡性能和速度

### 🛠️ script
包含各种辅助脚本工具，用于模型比较、性能测试、数据处理等任务。这些脚本帮助评估不同模型在速度和精度方面的表现。

### 🏋️ train
模型训练相关代码，包含目标检测模型(YOLOv5)和语义分割模型(Fast-SCNN)的训练代码，以及数据准备、后处理等模块。这部分代码用于从原始数据集训练得到可用于实际应用的模型。

## 核心功能

本项目研究基于深度学习的车辆道路障碍检测及碰撞预测方法，主要解决车辆行驶过程中的安全问题。系统通过结合目标检测、语义分割和目标跟踪技术，实现道路障碍物的检测、车道区域的识别以及潜在碰撞风险的预测，为智能驾驶系统提供决策支持。

### 🔍 关键技术

| 技术模块     | 实现方法   | 功能描述                       |
| :----------- | :--------- | :----------------------------- |
| **目标检测** | YOLOv5系列 | 检测道路上的车辆、行人等障碍物 |
| **语义分割** | Fast-SCNN  | 识别车道线和可行驶区域         |
| **目标跟踪** | DeepSORT   | 跟踪移动障碍物的轨迹和速度     |
| **碰撞预测** | TTC算法    | 计算与障碍物的碰撞时间         |

### ⚡ 性能优化
项目同时提供了C++和Python两种实现，分别适用于不同场景：

| 实现语言   | 适用场景       | 优化特点                         |
| :--------- | :------------- | :------------------------------- |
| **C++**    | 嵌入式设备部署 | 针对低功耗设备优化，实现实时处理 |
| **Python** | 研发测试环境   | 灵活开发，快速原型验证           |

## 亮点

- 🚀 **轻量化设计**: 针对嵌入式设备优化的模型架构，兼顾性能和资源消耗
- 🔄 **多任务融合**: 同时实现目标检测、语义分割和目标跟踪等多项功能
- ⏱️ **实时性能**: 经过优化的算法流程，确保在资源受限环境下的实时响应
- 🛡️ **安全预警**: 基于TTC算法的碰撞风险预测，提前预警潜在危险
- 🔌 **跨平台实现**: 提供C++和Python两种语言实现，适应不同应用场景

## 环境要求

详细的Python依赖库要求请参考`requirements.txt`文件。主要依赖包括：

- PyTorch (深度学习框架)
- OpenCV (计算机视觉库)
- NumPy (科学计算库)
- 其他相关依赖

C++实现部分依赖于PlatformIO环境，详细配置见`firmware/platformio.ini`。

## 使用说明

1. 安装依赖：`pip install -r requirements.txt`
2. 运行Python版本：`cd main_py && python main.py`
3. 编译C++版本：在PlatformIO环境中构建firmware目录
